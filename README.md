# 👥 Gerenciador de Pessoas

Aplicação desenvolvida para praticar JavaScript através do cadastro
e gerenciamento de pessoas.

O usuário pode informar um nome e uma idade, adicionar a pessoa à
lista e visualizar sua classificação por faixa etária.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Cadastro de pessoas
- Classificação por idade
- Exibição das pessoas cadastradas
- Remoção de pessoas
- Validação dos campos
- Estado vazio quando não existem cadastros

## Conceitos praticados

- Manipulação do DOM
- Eventos
- Funções
- Condicionais
- Arrays
- Criação dinâmica de elementos
- Manipulação de classes CSS
